# virtualized_list_display_none

`scene.rml` is the source markup for `assets/virtualized_list_display_none.riv`,
which `virtualized_list_display_none_test.cpp` loads. Its header comment says
what the scene is for.

Rebuild the `.riv` with a CLI built with the dev tools, from this directory,
then copy `build/virtualized_list_display_none.riv` into `assets/`:

    rive . --unsigned-riv
